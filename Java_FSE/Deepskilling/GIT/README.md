# Git Hands-on

This folder contains the Git hands-on solutions completed as part of the Cognizant Digital Nurture Java FSE training.

## Exercises

### 1. Git Basics and Configuration

* Git user name and email configuration
* Notepad++ integration with Git
* Creating a local Git repository
* Adding and committing files
* Git pull and push commands

File: `1. Git-HOL.txt`

### 2. Git Ignore

* Creating a `.gitignore` file
* Ignoring `.log` files
* Ignoring the log folder
* Verifying ignored files using Git status

File: `2. Git-HOL.txt`

### 3. Branching and Merging

* Creating and switching branches
* Adding and committing files in a branch
* Comparing branches
* Merging a branch with master
* Creating branches and merge requests in GitLab

File: `3. Git-HOL.txt`

### 4. Merge Conflict Resolution

* Creating different changes in two branches
* Identifying a merge conflict
* Resolving conflicts using P4Merge
* Committing the resolved changes
* Deleting the merged branch

File: `4. Git-HOL.txt`

### 5. Git Clean Up and Remote Push

* Checking the working-tree status
* Listing local and remote branches
* Pulling changes from the remote repository
* Pushing pending commits
* Verifying changes in the remote repository

File: `5. Git-HOL.txt`
